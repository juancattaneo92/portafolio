Invoice Scanner

A microservices pipeline that turns invoice PDFs and photos into structured data with OCR and a local LLM.

Python FastAPI PaddleOCR Llama
View repo How it works

What I built & why

Manually keying invoice data is slow and error-prone. This system takes a PDF or a phone photo and returns clean structured fields - vendor, line items, totals, dates - ready to drop into a ledger.

It is split into small services: one for OCR, one for LLM extraction, one for the API surface. The LLM runs locally so financial documents never leave the machine, and each service can be scaled or swapped on its own.

Why this stack

  • PythonFast to prototype and the richest ecosystem for OCR, ML, and glue code.
  • FastAPIAsync request handling and automatic schema docs made the service boundaries explicit.
  • PaddleOCRStrong accuracy on dense, low-contrast invoice text compared to the alternatives I tried.
  • LlamaRunning the model locally keeps sensitive financial documents off third-party APIs.
