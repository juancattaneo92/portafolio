Postrain

A point-of-sale training game that helps new employees build speed before their first shift.

JavaScript CSS Animations
Source is private

What I built & why

New hires lose time learning where things are on a POS screen while a line builds. Postrain is a game that drills that muscle memory - orders come in, you ring them up, and it scores you on speed and accuracy.

It mirrors a real POS layout closely enough that the practice transfers, with CSS animations giving the feedback that keeps it feeling like a game rather than a quiz.
