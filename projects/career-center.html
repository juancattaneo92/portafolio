Career Center App

A phone-friendly web app for running mock interviews with a voiced AI interviewer and rubric-based feedback.

Python FastAPI Anthropic Claude / Ollama RAG Custom Eval Harness Docker
Open live site Open the demo

What I built & why

Interview prep usually means either paying for a coach or rehearsing alone with no feedback. This app runs a full mock interview with a voiced AI interviewer (Piper TTS) you can do from your phone, then grades the session against a rubric.

Questions come from a curated bank, never invented by the model, so every run is predictable and fair. Grading is deterministic-first: a validity gate rejects non-answers with no model call, then one comparative LLM call runs per rubric criterion. It is local-first on Ollama with Claude as an optional upgrade, and a framework-free eval harness gates CI on junk-leak and mode-violation rates.

Why this stack

  • Python FastAPIAsync endpoints and clean schemas for the interview, grading, and TTS service boundaries.
  • Anthropic Claude / OllamaLocal-first on Ollama keeps it free to run; Claude is a drop-in upgrade when higher-quality grading matters.
  • RAGPulls questions from a curated bank so the model never invents prompts or drifts off-topic.
  • Custom Eval HarnessFramework-free, so CI can fail the build on junk-leak and mode-violation rates instead of vibes.
  • DockerOne command brings up the API, model runtime, and voice pipeline together.
