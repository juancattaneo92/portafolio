What I built & why

EnLista Restaurant waitlist app. Guests join from their phone, pick a party size, and watch their spot move up the line in real time, with a push notification the moment their table is ready. Staff run the whole queue from a tablet: notify, check in, seat, no-show, with a live table count, a service-pace control, daily history and CSV export.

Why this stack

  • Next.js 16 + React 19App Router route handlers for the queue API and a fast, phone-first UI for guests and staff.
  • TypeScriptOne shared model for parties, states, and the tablet dashboard keeps the queue logic consistent.
  • SupabasePostgres plus realtime subscriptions push line-position changes to every device instantly.
  • Tailwind CSS v4Rapid, consistent styling across the guest phone view and the denser staff tablet layout.
  • bcryptjsHashes staff passwords so the tablet console has real, low-friction auth.
  • web-pushSends the "your table is ready" notification even when the guest has closed the tab.
