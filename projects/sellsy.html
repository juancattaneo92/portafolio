Sellsy

An Etsy-inspired marketplace with auth, search, and a working cart.

Ruby on Rails React Redux PostgreSQL
View repo

What I built & why

A full-stack marketplace modeled on Etsy: users sign up, browse and search listings, and add items to a cart that persists. It was where I learned to wire a real relational backend to a React front end end to end.

Rails handles the API, auth, and data model; React and Redux drive the storefront. The interesting parts were search, cart state, and keeping the two layers honest about what data each owned.

Why this stack

  • Ruby on RailsConvention over configuration meant the CRUD and auth scaffolding came together fast.
  • ReactThe component model keeps each piece - menu, event list, gallery - isolated and easy to restyle.
  • ReduxPredictable state made the cart and search filters easy to keep in sync across the UI.
  • PostgreSQLRelational integrity for orders, listings, and users, with room to grow into more complex queries.
