Canalla SF

A home for a Peruvian pop-up on its way to a permanent San Francisco location.

Next.js React TypeScript Tailwind CSS
Open live site

What I built & why

Canalla started as a pop-up and needed a site that could grow with it, announce events now, become a full restaurant site later. I built it on Next.js so the same codebase covers both phases without a rebuild.

Content is data-driven: events, menu items, and location details live in structured files so updates are quick and the layout stays consistent. The visual direction is bold and food-forward to match the pop-up's energy.

Why this stack

  • Next.jsFile-based routing and static generation keep first loads fast and URLs clean without standing up a separate backend.
  • ReactThe component model keeps each piece - menu, event list, gallery - isolated and easy to restyle.
  • TypeScriptTypes on the content models caught shape mismatches before they ever reached the page.
  • Tailwind CSSUtility classes kept styling next to the markup and made the responsive pass quick.
