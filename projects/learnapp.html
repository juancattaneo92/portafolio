LearnApp

A Duolingo-style personal learning app for technical topics, with a source-grounded AI curriculum, full-screen lessons, XP, streaks, and spaced repetition.

Next.js 16 React 19 TypeScript Tailwind CSS v4 Drizzle ORM Ollama Brave Search API Vitest
Open live site Open the demo

What I built & why

Self-teaching a technical topic usually means bouncing between tabs with no structure and nothing to keep you coming back. LearnApp turns that into a guided, gamified path.

You pick something you want to learn and answer a couple of quick familiarity questions. The app searches the web for authoritative documentation and lets you approve or reject each source, then an AI generates a source-grounded curriculum, modules and lessons, that you can edit before approving. Each lesson is a distraction-free full-screen player: a short teaching passage followed by mixed exercises, multiple choice, fill-in-the-blank, flashcards, scenario write-ups, and timed true/false speed rounds. Mastering lessons earns XP, builds a daily streak, raises your level, unlocks the next lesson on a vertical path, and schedules the lesson for spaced-repetition review later.

Why this stack

  • Next.js 16 + React 19Server Components and route handlers for the generation pipeline, with a snappy client for the lesson player.
  • TypeScriptThe curriculum tree, exercise types, and progress model all share one schema end to end.
  • Tailwind CSS v4Drives the custom Duolingo-ish theme with Baloo 2, Nunito, and IBM Plex Mono.
  • SQLite + Drizzle ORMbetter-sqlite3 for zero-ops local storage; Drizzle for typed queries and migrations. bcryptjs handles 6-digit PIN auth with a session cookie.
  • Ollamallama3.1:8b generates curriculum, lessons, and exercises and grades answers; nomic-embed-text powers retrieval, all running locally.
  • Brave Search APIFinds candidate sources; @mozilla/readability, jsdom, and turndown extract clean page content to ground the curriculum.
  • Vitest + Testing LibraryCovers the exercise logic and progression rules where regressions would be easy to miss.
