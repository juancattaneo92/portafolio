Casita Hub

A household hub PWA for shared shopping lists, to-dos, a weekly planner, and family stats.

React 19 Next.js 16 TypeScript Tanstack Query Flask SQLite PWA
Open live site Open the demo

What I built & why

Running a household means juggling shopping, chores, and plans across more than one person, usually spread over texts and sticky notes. Casita Hub puts all of it in one installable app that works on phone and desktop.

It has shared shopping lists with categorized items, drag-to-reorder, and price-history tracking; shared to-do lists with due dates and per-person assignment; a weekly planner board; and a cross-module stats dashboard with both personal and family charts.

Why this stack

  • React 19 + Next.js 16App Router and server components for a fast first paint on the phone, where this app mostly lives.
  • TypeScriptShared types across lists, tasks, and planner keep the cross-module stats dashboard honest.
  • TanStack QueryOptimistic updates and cache invalidation make drag-to-reorder and shared edits feel instant.
  • Flask + SQLiteA small, self-hostable API and a zero-ops database, right-sized for a single household.
  • PWAInstalls to the home screen and keeps working offline, so it behaves like a native app without a store.
